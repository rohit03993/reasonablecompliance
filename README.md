# Reasonable Compliance

Corporate legal and regulatory compliance website — modern, lightweight, mobile-first.

## Stack

- Astro 7 + Tailwind CSS 4
- Decap CMS (`/admin`)
- Netlify (hosting, forms, Identity)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
